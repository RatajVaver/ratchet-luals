This repository contains the definitions files for Lua libraries and functions from [Ratchet](https://ratchet.ratajmods.net) (Conan Exiles Script Extender).

Use [Lua Language Server](https://github.com/LuaLS/lua-language-server) or similar extension to load these files for syntax hightlighting, autocompletion, in-editor documentation, and more.

These definition files follow universally used Lua annotations and should therefore work with any extension that supports them.
